# Trading Bot

A simple trading bot for market and limit orders.

## Installation

1. Clone the repository

   ```bash
   git clone https://github.com/kamranskhan54/trading-bot.git
   cd trading-bot
   ```

2. Install dependencies

   ```bash
   pip install -r requirements.txt
   ```

3. Set up your environment by copying `.env.example` to `.env` and adding your credentials.
   
## Usage

Run the bot using the command:
```bash
python cli.py
```
